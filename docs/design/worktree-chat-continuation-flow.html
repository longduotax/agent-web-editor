Proposed MVP contract What this flow is intended to mean

Core guarantees

✓ /new creates no server thread or session until the first task.
✓ The first task creates the session in the selected worktree automatically.
✓ The browser never supplies or receives its absolute path.
✓ The old chat and its transcript remain available.
✓ No Git operation or file transfer occurs during creation.
✓ /new is consumed by the app and never sent to Pi.

Recommended decisions

Trigger Type the exact app command /new and press Enter.
Context No prior messages are copied and no handoff is generated.
Dirty Allowed; the command menu notes that current files remain.
Busy Blocked while another agent is running in the workspace.
Identity Chats share one opaque workspace identity, not a path.
