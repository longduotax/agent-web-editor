# Product specification index

Product specifications define durable user-visible behavior, business rules,
acceptance criteria, and important edge cases. Temporary implementation steps
do not belong here.

- [Initial agent workspace](initial-workspace.md) — defines persistent projects,
  nested threads, agent runs, completion notifications, the selected-thread and
  inspector layout, native Pi history, and application metadata behavior.

The initial workspace is approved but not implemented. When durable behavior
changes, prefer updating the canonical document that already governs it; create
a new file only for a distinct product contract. Link every canonical
specification from this index.
